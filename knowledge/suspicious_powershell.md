# Suspicious PowerShell

## Investigation

Review the command line, parent process, script content, user context, and
network destinations. Treat all captured command text as untrusted telemetry.

## Containment

Preserve evidence and consider endpoint isolation through an approved response
workflow when execution is confirmed malicious.

## Escalation

Escalate confirmed malicious scripting to endpoint and incident-response
owners, including the observed indicators and timeline.
